# React Minimalist UI Component Example

This example demonstrates React's core function as a minimalist UI library. It showcases a simple functional component managing its own state and rendering dynamically, all within a single HTML file without any complex build tools. This highlights React's focus solely on user interface creation, allowing developers the freedom to choose other libraries for concerns like routing or global state management.

## Language

`html`

## How to Run

Save the code as `index.html`. Open `index.html` in your web browser.
